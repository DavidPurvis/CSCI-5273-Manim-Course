# Dish 17.3: Practice question 3: prefix arithmetic

## 17.3.question
Practice question 3. For 172.16.5.130/22, give the mask, the network, the broadcast address, and the conventional usable count. Then decide whether 172.16.7.12 is on the same subnet.

## 17.3.predict
Do the arithmetic on paper. Remember to show your work.

## 17.3.mask
A slash 22 means 22 network bits, so the mask is 255.255.252.0. The boundary falls inside the third byte. Six of that byte's bits are network bits and two are host bits, so third-byte blocks have size 4.

## 17.3.network
The third byte is 5, and 5 lies in the block from 4 through 7. So the network is 172.16.4.0, and the broadcast is 172.16.7.255. That leaves 10 host bits, so 2 to the 10th, minus 2, gives 1,022 usable addresses.

## 17.3.same
172.16.7.12. Its third byte is 7, which sits in the same block. So yes, it's on the same subnet, even though 5 and 7 look different.

## 17.3.trap
The tempting answer treats this like a slash 24: network 172.16.5.0, broadcast 172.16.5.255. That ignores the mask. The host part begins inside the third byte, so the block crosses several values of it.

## 17.3.marks
On marks: one point for each requested result.
