# Dish 17.5: Practice question 5: longest match

## 17.5.question
Practice question 5. Installed routes are 10.0.0.0/8 to A, 10.4.0.0/16 to B, 10.4.8.0/21 to C, and slash 0 to D. Choose outputs for 10.4.9.7, 10.4.20.1, 10.8.1.2, and 192.0.2.8. Then explain why a lower-cost slash 8 would not replace a matching slash 21 during ordinary lookup.

## 17.5.predict
Choose all four outputs before going on.

## 17.5.first
Start with 10.4.9.7. It's inside the slash 8, and inside the slash 16. For the slash 21, third-byte blocks have size 8, and 9 lies in 8 through 15. So it matches that too, and the longest wins: output C.

## 17.5.rest
10.4.20.1 matches the slash 8 and the slash 16. Its third byte, 20, is outside 8 through 15, so the slash 21 doesn't match. Output B. 10.8.1.2 matches only the slash 8 and the default. Output A. And 192.0.2.8 matches only the default: output D.

## 17.5.why
Why doesn't cost matter? Cost belongs to route selection, which happens before a prefix is installed. Forwarding among installed matches uses prefix length alone. So a matching slash 21 beats a slash 8, however cheap the slash 8 looks.

## 17.5.trap
The tempting answer lets the cheaper route win, or takes whichever route is listed first. Neither one affects an ordinary lookup.

## 17.5.marks
On marks: four points for the outputs, and one for the distinction.
