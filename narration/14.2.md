# Dish 14.2: CDMA

## 14.2.question
In a crowded room, two pairs can talk at once if one pair speaks English and the other speaks French. You filter out what you can't decode. Could two senders transmit on the same frequency at the same time, with the receiver still separating them?

## 14.2.codes
That's the idea behind code division multiple access. Each sender gets its own code, a sequence of plus and minus ones, called chips. Sender one uses 1, 1, minus 1, minus 1. Sender two uses 1, minus 1, 1, minus 1. The magic is in how these two relate. Multiply them chip by chip, and add: 1, minus 1, minus 1, plus 1. That's zero. The codes are orthogonal.

## 14.2.send
To send a bit, multiply the whole code by the bit's value. Sender one sends plus 1, so it transmits its code unchanged. Sender two sends minus 1, so it transmits its code flipped. On the air, the signals simply add. Chip by chip, the receiver gets 0, 2, minus 2, 0. This sum looks like neither sender.

## 14.2.decode
Decode. To hear sender one, take the dot product of the received signal with c 1, then divide by 4, the code length. 0 times 1, plus 2 times 1, plus minus 2 times minus 1, plus 0. That's 4, over 4, which is plus 1. Sender one's bit is recovered. With c 2, 0, minus 2, minus 2, plus 0 gives minus 4, over 4, which is minus 1. Why does this work? Correlating with c 1 leaves sender two's contribution multiplied by c 1 dot c 2, and that's zero. Sender two simply vanishes.

## 14.2.rule
In formula form: the sum of each bit times its code goes out on the air. The receiver takes z dot c k, over M, the code length. This is an ideal model. It assumes synchronized chips and well balanced powers. It's a clean demonstration, not a promise of zero interference in the real world.

## 14.2.pitfall
Don't treat orthogonality as magic. It cancels the other sender only under ideal conditions: synchronized chips, balanced powers, and little noise.

## 14.2.changed
Change one bit. Sender one also sends minus 1, so both bits are minus 1.

## 14.2.predict
What's the new sum z? And what do you get when you decode each sender?

## 14.2.answer
z is minus 2, 0, 0, 2. Correlate with c 1: minus 2, plus 0, minus 0, minus 2, which is minus 4, over 4, or minus 1. Correlate with c 2: also minus 4 over 4, or minus 1. Both bits come out right. Codes are one way to share a medium, and cellular networks have used them. But Wi-Fi takes a completely different approach. Before that, a laptop has to find a network to join in the first place.
