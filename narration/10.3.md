# Dish 10.3: Path vector

## 10.3.question
Between organizations, neither method fits. Would your company publish its internal map to its competitors, as link state needs? Would it accept a single cost number from them, whose meaning it can't check? Networks run by different owners need something else.

## 10.3.limits
Consider why each one breaks down. Link state floods topology, which reveals private structure, and it requires a common metric. Distance vector hides the structure, so it's on the right track. But one bare number has two problems. Different networks measure cost differently, so the numbers aren't comparable. And the number hides the route, so nobody can apply a preference such as, avoid that competitor.

## 10.3.fix
The fix is to advertise the whole path. Instead of saying, I'm 3 away, a network says, I can reach it through networks 3, 2, 1. Each network that passes this along adds its own identifier at the front. This is path-vector routing, and it's the basis of BGP.

## 10.3.loop
Benefit one is easy loop detection. Say AS 3 offers the path 3, 2, 1 back to AS 1. AS 1 looks through the list, sees itself, and rejects it. It doesn't need to count, or wait. The loop is visible right there in the data.

## 10.3.policy
Benefit two is policy. Now that you can see the whole route, you can apply your own judgment. A network may prefer a longer path, for business reasons. It may avoid one that crosses a particular network. It may decide not to pass a route on to some neighbor. There's no shared definition of best anymore. That flexibility is the point. But it also means that loop-free does not imply everyone's choices fit together. We'll return to that.

## 10.3.pitfall
Don't overclaim here. Rejecting paths that contain your own AS stops loops. It doesn't promise immediate convergence, and it doesn't rule out policy oscillation.

## 10.3.changed
Test the rule. AS 4 receives the path 3, 2, 1. Next, AS 2 receives the path 3, 4, 2, 1. And then AS 5 is offered a path of length two and a path of length five.

## 10.3.predict
Which paths get rejected as loops? And must AS 5 choose the shorter one?

## 10.3.answer
AS 4 accepts: it isn't in the list. AS 2 rejects: its own number appears. And AS 5 may take either one. Its local policy can prefer the longer path. Path vector tells it what's possible, and it decides what's best. One routing idea remains in this lecture, and it asks a different question. Once a path is known, must every router really look up the address all over again?
