# Dish 17.6: Practice question 6: queues

## 17.6.question
Practice question 6. Input FIFO X holds two packets: first, one for output 1, then one for output 2. Another input wins output 1, while output 2 sits idle. Name and explain the problem. Then, does a faster fabric fix sustained 20 megabits per second of demand on a 10 megabit per second output?

## 17.6.predict
Name the problem, and decide about the faster fabric.

## 17.6.hol
The problem is head of line blocking. X's first packet can't use output 1 during this slot. The packet behind it wants output 2, which is free. But a first-in, first-out queue won't let it pass.

## 17.6.overload
The overload. 20 megabits per second arrive, and the output sends only 10. So the backlog grows at 10 megabits per second, for as long as that lasts. A faster fabric only delivers packets to that same output sooner. The output link's rate is the limit.

## 17.6.trap
The tempting fix is a faster fabric, or a bigger buffer. A bigger buffer absorbs a burst, but under sustained overload it only adds delay before the same drops.

## 17.6.marks
On marks: three points for the head of line mechanism, and two for the overload reasoning.
