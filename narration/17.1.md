# Dish 17.1: Practice question 1: switch learning

## 17.1.question
Practice question 1. This walkthrough follows a generated practice midterm, not your instructor's exam, so use it to test your reasoning, not to predict questions. If you haven't tried the test yet, stop now and take it first. A switch starts with an empty table. A is on port 1, B is on port 2, and C is on port 3, all in one VLAN. Trace A to B, then B to A, then C to B. After each frame, give the table change and the output ports.

## 17.1.predict
Work all three frames before going on.

## 17.1.first
First frame, A to B. The switch reads the source address, so it learns that A is on port 1. Then it looks up the destination. B is unknown, so it floods out ports 2 and 3.

## 17.1.second
Second frame, B to A. Source first: B is on port 2. Now the destination, A, is in the table, so the frame goes only out port 1.

## 17.1.third
Third frame, C to B. The source teaches the switch that C is on port 3. B is known, so the frame goes out port 2. The final table is A on 1, B on 2, and C on 3.

## 17.1.trap
The tempting mistake. After the first frame, many people write B into the table, because A mentioned B. But a destination address tells the switch nothing about where B is. Only a frame sent by B can do that.

## 17.1.marks
On marks: three points for the three forwarding actions, and two for source learning with the correct final table.
