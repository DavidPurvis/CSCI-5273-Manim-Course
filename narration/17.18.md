# Dish 17.18: Practice question 18: CDMA

## 17.18.question
Practice question 18. Let c 1 be 1, 1, minus 1, minus 1, and let c 2 be 1, minus 1, 1, minus 1. d 1 is minus 1, and d 2 is plus 1. Compute the summed chip vector z, and recover both bits by correlation. Then state one ideal-model assumption.

## 17.18.predict
Compute z and both correlations on paper.

## 17.18.sum
z is minus c 1, plus c 2. Chip by chip, that's 0, minus 2, 2, 0.

## 17.18.decode
Correlate with c 1: 0, minus 2, minus 2, plus 0 gives minus 4, over 4, which is minus 1. Correlate with c 2: 0, plus 2, plus 2, plus 0 gives plus 4, over 4, which is plus 1.

## 17.18.assumption
One ideal assumption: synchronized orthogonal codes, with suitable power and noise conditions.

## 17.18.trap
The tempting slips are dividing by 2 instead of the code length, or forgetting that a bit of minus 1 flips the whole code. M here is 4.

## 17.18.marks
On marks: two points for z, one per decoded bit, and one for the assumption.
