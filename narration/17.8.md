# Dish 17.8: Practice question 8: directory roles

## 17.8.question
Practice question 8. A resolver receives an NS referral, then a CNAME, then an A record. Explain each value's role. Distinguish the client's recursive request from the resolver's iterative queries, and give one cache-freshness tradeoff.

## 17.8.predict
Give the three roles and the distinction before going on.

## 17.8.records
An NS record names an authoritative server for a zone. It's a delegation, telling the resolver whom to ask next. A CNAME gives an alias's target hostname, so the resolver goes on to look up that name. And an A record finally supplies an IPv4 address.

## 17.8.queries
Recursive means, obtain it for me. That's the client's request to its resolver. Iterative means, answer or tell me whom to ask. That's how the resolver queries the hierarchy.

## 17.8.ttl
The tradeoff: a long TTL reduces work and latency, but it delays noticing changes.

## 17.8.trap
The tempting mistake treats every record as an address. NS and CNAME both give host names. Only the A record gives the address.

## 17.8.marks
On marks: one point for each of the three record roles, one for the query distinction, and one for the tradeoff.
